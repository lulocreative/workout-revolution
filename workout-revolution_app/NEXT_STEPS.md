# Next Codex improvements (priority order)

1. **Reliable sync across devices:** Opt-in sign-in and encrypted cloud backup, keeping local-first mode. Only after the owner approves storing health and progress data off-device.
2. **History editing:** Allow correcting and removing individual historical sets with a visible audit trail, plus importing a CSV export from SATS if available.
3. **Better body progress:** IndexedDB image storage, paired date comparisons, optional waist/arm change charts, local-only by default.
4. **Coach controls:** Edit per-set target loads and equipment setup IDs through the UI, with required reason and tests for comparison logic.
5. **Calendar:** Schedule three or four sessions based on availability, recovery and actual weekly volume, without moving exercises purely for variety.
6. **Native/mobile integrations:** HealthKit/Apple Health and exercise notifications only if permission is explicitly granted.
7. **Optional conversational coach:** If requested, add an authenticated server-backed LLM to discuss decisions, but require evidence from actual logs and display uncertainty. Never silently apply its suggested program changes.

Keep the simple, one-exercise-at-a-time workout flow. It is more important than ornamental charts.
